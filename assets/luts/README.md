# Original illustrative LUTs

Four 17³ Cube LUTs, normalized domain 0..1, red fastest then green then blue. Mild original grades, not face-aware transforms. Input/output assumed normalized sRGB-coded values for these simple artistic assets. Blend the graded result with source for intensity and validate renderer/parser ordering. Balanced Mono converts to weighted luma using 0.2126/0.7152/0.0722 coefficients as an artistic approximation, not a calibrated luminance measurement in gamma-coded space.
