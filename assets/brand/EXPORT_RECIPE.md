# Brand export recipe

Original SVG sources are editable. Product name PortraitLab is provisional. App icon source uses 1024 × 1024 square viewBox and opaque background. Export through a trusted SVG rasterizer/design tool at currently required Apple/Android sizes, inspect sharpness, and follow current store alpha/mask/adaptive-icon guidance. Raster app icon/splash/store screenshots are not claimed included. Wordmark is editable text using Inter fallback; outline text for final export if desired and preserve font license. Do not rasterize FaceApp's branded assets.
